# Nobita Bgm Music Academy Website

Oru music academy-ku vendi create cheytha oru modern, responsive, single-page web application (SPA) aanu ithu. Ithil music courses, live events, gallery, student reviews, mattumalla oru powerful owner management panel-um include cheythirikkunnu.

## 🚀 Technologies Used

* **HTML5 & CSS3**: Modern styling, grid/flexbox layouts, custom variables, animations, and fully mobile-friendly design.
* **JavaScript (ES6+)**: Custom SPA routing, interactive carousels, form validations, and dynamic DOM rendering.
* **Google Firebase (Firestore & Auth)**: Real-time database for reviews and media management, plus secure Owner Login/Logout authentication[cite: 1].
* **Google Apps Script**: Backend integration for handling form submissions directly to Google Sheets and Gmail[cite: 1].
* **WhatsApp & Email Integration**: Direct one-click enquiry sharing and messaging via WhatsApp and Gmail.

## ✨ Key Features

1. **Dynamic Navigation & Routing**: Seamless single-page experience across Home, About, Instruments/Courses, Events & Services, Gallery, Reviews, and Contact pages[cite: 1].
2. **Student Reviews System**: Visitors can submit reviews, which are securely stored and managed via Firebase Firestore[cite: 1].
3. **Interactive Media & Video Players**: Custom video players with play, pause, mute, and fullscreen controls for classes and event moments[cite: 1].
4. **Direct WhatsApp & Form Enquiries**: Admissions, event bookings, and general enquiries automatically connect users to WhatsApp with pre-filled message templates[cite: 1].
5. **Dynamic Owner Panel**: Authorized academy owners can securely log in to approve/remove reviews, upload media, and dynamically edit website content and details without touching code[cite: 1].
6. **Google Sheets & Apps Script Integration**: Form submissions log directly into Google Sheets for easy student tracking[cite: 1].

## 📂 Project Structure

* `index.html`: Complete core application containing all HTML structure, CSS styling, client-side routing, and Firebase integration logic[cite: 1].
* `assets/img/`: Folder containing course photos, academy images, logos, and service visuals[cite: 1].
* `assets/video/`: Folder containing promotional and classroom video files[cite: 1].

## ⚙️ Setup & Deployment

1. Clone or download this repository.
2. Upload the files to your GitHub repository (`nobita-bgm-music-academy`)[cite: 1].
3. Deploy the repository instantly using **Netlify** or **Vercel**[cite: 1].
4. Connect your custom domain (e.g., `www.nobitabgmmusicacademy.com`) through Netlify/Vercel DNS settings[cite: 1].
